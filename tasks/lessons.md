# Lessons

## 2026-10-27 - Design for emotion, not for data display
The user said the first version was "remotely not at the level" expected: it showed facts but did not evoke emotion, and pointed at the SpaceX Starship page as the bar.
I built a polished dashboard (lists, tiles, glass panels) around one 3D render instead of a cinematic story.

Rules:
- When a brief asks for "aesthetic", "epic" or "futuristic", find the subject's own flagship site (here spacex.com) and study it in the browser before the design plan.
- Lead with story and scale (full-screen moments, real imagery, motion, few words), and put data second, as supporting detail.
- Show the user one hero or section mock early to check the emotional direction before building out every section.
